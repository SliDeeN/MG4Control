ESC et somnolenceESC and drowsiness

Boutons ON / OFF confirmés par une relecture de l'état du véhicule.

ON / OFF buttons confirmed by re-reading the vehicle state.

En savoir plusLearn more

Les boutons expriment une intention, puis l'app relit l'état 700 ms plus tard et c'est cette relecture qui décide lequel s'allume. État illisible = aucun bouton allumé, plutôt qu'un état deviné. Dans un profil, ESC et somnolence ne sont écrits que si le profil les configure.

The buttons express an intent, then the app re-reads the state 700 ms later and that reading decides which one lights up. Unreadable state = no button lit, rather than a guessed state. In a profile, ESC and drowsiness are only written if that profile configures them.

One switch per tab: switched off, the profile leaves that category alone.

En savoir plusLearn more
